Quick Actions

Connect WhatsApp Device

Enter country code and digits only. Do not include +, spaces or dashes.
Pairing requires a deployed backend using the official WhatsApp-compatible connection library. This HTML intentionally does not fabricate pairing codes or collect WhatsApp credentials.

Pairing Instructions

  1. Enter your WhatsApp number with country code.
  2. Select an available server.
  3. Request a pairing code from the connected backend.
  4. Open WhatsApp → Linked Devices → Link a Device.
  5. Choose linking with phone number and enter the code.
Never share your pairing code or session files.

Bot Settings

AI Integration

Add your AI provider key securely on the backend host as an environment secret. Never place API keys in this HTML or public GitHub repository.

Deployment Guide

  1. Deploy the Node.js bot backend as a persistent service.
  2. Attach persistent storage for WhatsApp session credentials.
  3. Set environment variables for the backend URL and AI provider key.
  4. Connect this frontend to authenticated backend endpoints.
  5. Use server-side limits and monitoring for up to 50 sessions per server, subject to host capacity and WhatsApp rules.
This file is the frontend only. It cannot independently connect WhatsApp, create real pairing codes, host bot sessions, or guarantee 24/7 uptime.
