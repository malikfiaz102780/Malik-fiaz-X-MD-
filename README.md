⚙️ Installation

Install Node.js and npm first.

Install project dependencies:

npm install

🔗 WhatsApp Pairing

Run:

node pair.js

Enter your WhatsApp number with country code when requested.

Open WhatsApp:

Settings → Linked Devices → Link a Device

Choose the phone-number linking option and enter the pairing code.

🚀 Start Bot

npm start

🔐 Security

- Keep your WhatsApp session private.
- Never share your pairing code.
- Do not upload session credentials publicly.
- Keep private information out of public files.
